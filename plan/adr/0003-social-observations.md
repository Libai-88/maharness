# ADR 0003：社会健康改为观察指标

## 背景

当前社会健康分是负载、福利、异常、预算、协作关系的等权平均，并以 `/100` 展示；协作关系在团队完成/拒绝时批量写 `0.9/0.2`。这些数字看起来像客观测量，实际权重和样本没有校准依据。

## 决策

1. 删除社会健康的单一 `/100` 聚合分。
2. API 返回 `observations[]`，每项包含指标、值、单位、分子/分母、样本量、质量（observed/insufficient/unknown）和公式。
3. 关系指标只允许从实际交接、冲突、复核等可核对事件累计；样本不足显示 unknown，禁止按任务结果批量赋值。
4. UI 使用“社会观察”而不是“健康评分”；不把启发式指标包装成客观测量。

## 后果

- 破坏 `/api/organization/society` 和 `/api/workbench/summary` 的 `health.score` 字段；API schema 升到 2。
- 现有测试和 UI 必须同步更新，历史聚合分不再保留。
- 指标可审计性提高，但短期 UI 信息密度下降，这是有意取舍。

## 回滚

恢复到旧快照的 `health` 字段只作为只读历史展示；不回滚为可写的伪精确分。
