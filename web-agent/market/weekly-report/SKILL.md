# 周报生成指南

## 何时使用
用户要求"写周报/工作总结/本周进度"时读取本指南并执行。

## 流程
1. 先了解背景：问清周报周期（本周/上周）与受众（领导/团队/客户）；
2. 有工作区可用时，优先检查 git 提交记录（`git log --oneline --since="7 days ago"` 等）获取真实进展，不要编造；
3. 按模板组织内容，突出结果与数字。

## 模板
```markdown
# 周报（M月D日 - M月D日）

## 本周完成
- 事项 1（结果/产出，尽量带量化指标）
- 事项 2

## 进行中
- 事项（当前进度、下一步）

## 风险与阻塞
- 问题（影响、需要的支持）

## 下周计划
- 事项 1
- 事项 2
```

## 规则
- 只写有依据的内容（来自 git 记录/文件/对话），不确定的标注"待确认"；
- 每条一句到两句话，避免流水账；优先写结果与影响；
- 周报标题含日期范围。
