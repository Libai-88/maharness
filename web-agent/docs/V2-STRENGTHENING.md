## 运行能力

| 能力 | 当前契约 |
| --- | --- |
| 完整观察读取 | 自定义工具集合包含运行时提供的 recall_tool_result；结果按任务隔离、持久保存并支持分页；同名覆盖返回 TOOL_DEFINITION_CONFLICT |
| 恢复输入 | 核心运行指令按结构化身份组装；补充消息只投递一次；恢复用量增量结算 |
| 批次断点 | 执行前保存原生调用批次、已有观察及结果标识；恢复补回已确认结果，尚未开始的调用返回 TOOL_INTERRUPTED，并闭合执行记录 |
| 恢复边界 | 缺少原生批次或执行边界返回 CHECKPOINT_INCOMPLETE；存在未知副作用返回 EFFECT_OUTCOME_UNKNOWN，不自动重放 |
| 工具目录 | 按 schema token 体积启用发现；全部工具可容纳时直接提供；必需读取入口和仍获授权的已启用工具保留；工具顺序稳定 |
| 运行诊断 | 记录实际调用的提供商与模型、消息和 schema 的本地 token 估算、来源、尝试标识、恢复断点和输入指纹；历史缺失字段显示未记录 |
