# maharness AI 原生运行时

maharness 采用模型主导决策、运行时提供能力与边界的架构。默认循环组装模型输入、调用模型、执行原生工具调用并回填观察；规划、研究、记忆、技能和委派通过可选工具与能力提供。

## 任务与执行

`RunService` 管理主任务、子任务、恢复执行、取消和补充消息。对话保存在会话中；目标、授权、预算、状态、断点、工具结果和递增事件序号保存在任务中。页面断开只解除订阅，服务重启后由用户明确恢复任务。

已确认的工具结果从持久记录恢复；尚未开始的调用返回中断观察；副作用未知或缺少执行边界的旧断点拒绝自动恢复。模型结束回答表示执行结束，机器验收状态独立展示。

## 模型调用与费用

主循环、历史摘要、视觉、MCP sampling、向量检索和连接检测通过统一调用边界。每次实际请求记录用途、所属任务、父任务、模型身份、状态、用量来源和价格来源。辅助请求共享任务取消信号与模型执行池；维护请求使用独立持久账本。显式截止时间会取消在途调用。

普通任务默认使用费用提醒模式。超出提醒额度或用量不完整时，任务可继续，用户可在结束后核对并确认。显式硬限制模式必须在调用前可靠预留；价格未知、缺少输入计费上界或无法保证输出限制时拒绝发起调用。子任务用量进入同一祖先账本，重复回执只结算一次。

供应商缺失 usage、响应中断和未知价格保留为不确定数据，不能记为已确认的零成本。向量接口未提供用量与价格时亦如此。用户配置的价格属于配置依据，不等同于供应商账单。

## 工具与权限

工具契约包含版本、输入及输出 schema、副作用和权限声明。执行器统一验证参数、授权、取消、执行结果和副作用边界。长结果保存完整内容并提供分页读取引用；文件写入通过版本或内容匹配报告冲突。

工作区默认使用常规权限，开发者权限由用户明确开启。子任务继承权限上限，不能扩大授权。框架修改在隔离 Git worktree 内完成，用户审阅并采纳确定版本后应用；运行实例更新或重启由用户触发。应用守卫与进程模式不提供 OS 级安全隔离。

## 上下文

原始历史、运行事件和模型输入视图分开保存。上下文通过结构化来源、作用域、信任等级及保留策略管理；网页、文件、记忆和插件观察保持参考材料身份。必需约束在压缩时保留，超出模型容量时明确报告。

历史文本前缀只在旧数据迁移时识别。运行中的用户意图与保留规则依据元数据判断。默认关闭相似回答跳过模型的缓存；工具缓存与供应商前缀缓存保留各自的有效范围。

## 产品入口与兼容

主工作台固定展示会话、文件、工作台和自动化，并在空会话中呈现办公、学习与自动化任务入口。事项、项目、笔记、自动化、最近运行与产物共享持久状态；模型按用户明确要求更新这些记录。诊断包含模型输入组成、工具完整结果、子任务、产物及模型调用账本。费用确认保存用户确认时间，不改写原始回执。

运行时与插件采用 v3 契约，数据库 schema 为 15。加载器接受 v2 插件并通过兼容适配层补齐默认元数据，新插件声明 v3。迁移前保存数据库、配置与插件清单备份；旧显式预算保持硬限制语义，未知字段不推断为授权。回滚数据库和配置不会撤销文件或外部系统中已发生的操作。
