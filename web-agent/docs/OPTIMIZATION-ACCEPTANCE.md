## 运行方式与边界

```powershell
npm run eval:optimization
npm run eval:optimization -- --report evals/reports/<新目录>/targeted.json
```

报告文件采用独占创建，已有文件不能覆盖。脚本运行固定测试集、记录基准版本与工作源码指纹，并测量固定目录；不依赖真实模型凭据，不发起真实模型请求。

本轮没有运行真实模型全量矩阵。确定性结果不能证明自主模型成功率、供应商协议兼容性、固定模型身份或非零费用门禁通过，也不替代 [完整评测记录](COMPOSABILITY-ACCEPTANCE.md) 中的发布门禁。可信宿主 JavaScript 的取消属于协作语义；源码检查与 process 模式均不构成 OS 级安全隔离。
