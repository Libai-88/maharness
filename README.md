# maharness

面向日常办公与学习的 AI 工作台，直接处理文件、资料和轻量自动化任务，并通过插件持续扩展。

底层保持 AI 原生 Agent 操作系统架构：薄内核 · 全插件化 · 全程可观测。

**万物都是插件：agent 可以自己定义自己。** 只有内外之分：内部是唯一保持不变的 Agent 核心（kernel/），其余一切能力都通过可插拔的插件实现（外部）。
